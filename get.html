Installer FODX Facture

Devis et factures en MAD. Gratuit, sans compte. Vos données restent sur votre appareil.

Site web

Utilisez l’application directement dans le navigateur.

Ouvrir l’application

Android

  1. Ouvrez l’application dans Chrome.
  2. Appuyez sur Installer l’app en haut, ou sur ⋮ › Installer l’application.

Scannez avec votre téléphone

Windows et Mac

  1. Ouvrez l’application dans Chrome ou Edge.
  2. Cliquez sur l’icône d’installation dans la barre d’adresse, ou sur Installer l’app.

iPhone

  1. Ouvrez l’application dans Safari.
  2. Partager › Sur l’écran d’accueil.

Important : les données sont enregistrées uniquement sur l’appareil. Exportez une sauvegarde JSON régulièrement (Réglages › Sauvegarde). FODX Facture ne garantit pas la conformité fiscale : vérifiez vos obligations avec un comptable.
